# FactoryMind

A full-stack predictive maintenance platform modeled on the MBUSI manufacturing plant in Tuscalooa, Alabama.

## Functionality
- Tracks equipment, work orders, and parts usage via a relational database
- Streams simulated sensor telemetry via Azure Event Hubs
- Predicts equipment failure within 30 days using an XGBoost classifier
- Monitors model drift with Evidently AI
- Visualizes KPIs in a Power BI embedded dashboard

## Tech Stack
- ASP.NET Core 10.0
- Azure SQL
- Dapper
- Azure Event Hubs
- scikit-learn
- XGBoost
- MLflow
- Evidently AI
- PySpark
- Power BI
